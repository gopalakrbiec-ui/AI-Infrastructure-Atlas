Frontier compute is no longer just a GPU.

The unit of design has climbed from chip → server → rack → pod → datacenter → multi-site fabric. Every generation improves arithmetic, but memory capacity, bandwidth and interconnect increasingly determine how much of that arithmetic is useful.

02 · THE FOUR BOTTLENECKS

FLOPS alone don't build a frontier machine.

C

Compute

Tensor cores perform the matrix multiplications. Lower precision and sparsity increase peak arithmetic throughput.

  • BF16 / FP8 / FP4
  • Transformer engines
  • Kernel efficiency
M

Memory

HBM must hold weights, optimizer shards, activations and KV state while feeding compute fast enough to avoid stalls.

  • HBM capacity
  • HBM bandwidth
  • Memory placement
N

Network

Tensor, data, pipeline and expert parallelism exchange huge volumes of state. Network topology becomes algorithmically visible.

  • NVLink / ICI
  • InfiniBand / Ethernet
  • All-reduce + all-to-all
